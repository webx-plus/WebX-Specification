# Border Radius

Defines the corner rounding on an element.

```css
border-radius: <size>;
border-radius: 8px;
```

![Different boxes with different border radius values](../../media/border-radius-1.png)
![Infographic showing border radius](../../media/border-radius-2.png)

## Syntax

`border-radius: <size>;`

Value must be of type [\<size>](../data-types/size.md).
