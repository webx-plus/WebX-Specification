# Border Color

Defines the color of the border on an element.

```css
border-color: <color>;
border-color: #ff00ff;
```

![Some text with a pink border](../../media/border-color.png)

## Syntax

`border-color: <color>;`

Value must be of type [\<color>](../data-types/color.md).
